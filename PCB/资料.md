对应板芯片的 MicroPython：[ESP32_GENERIC_S3](https://micropython.org/download/ESP32_GENERIC_S3/)  
模组：**ESP32-S3-WROOM-1-N16R8**（16MB Flash + **8MB Octal PSRAM**；部分资料写 N16S8，含义相同）。不要刷非 S3 固件。

**固件必须选 SPIRAM_OCT 版本**（文件名含 `SPIRAM_OCT`），例如仓库内  
`firmware/ESP32_GENERIC_S3-SPIRAM_OCT-20260824-v1.29.0.bin`。  
若误刷普通 `ESP32_GENERIC_S3-*.bin`，启动会报 `PSRAM chip is not connected` / `Failed to init external RAM`。

开发一个感应狗上厕并完成自动冲水的项目。

硬件：**红外传感器**判断占用；**按压电机**（A4950，PWM 调 IREF 等效电压 + H/L 正反转）拉动冲水杆；**粉碎电机**（24V + MOSFET）独立控制。

## 接线 / GPIO（与原理图 net 一致）

| 功能 | GPIO | 原理图 net | 说明 |
|---|---|---|---|
| 红外输入 | **1** | HR_INPUT | 内部上拉。触发（宠物在）= **低电平**；未触发 = **高电平** |
| 按压 PWM | **10** | IREF | PWM 调占空比，经 RC 到 A4950 VREF |
| 按压方向 H | **11** | MOTOR_H | 与 L 配合正反转，**禁止 H、L 同时为高** |
| 按压方向 L | **12** | MOTOR_L | 同上 |
| 粉碎电机 | **9** | MOTOR_24V | 高电平打开 MOSFET，24V 电机转 |

按压电机逻辑（A4950 IN1/IN2）：

| MOTOR_H (11) | MOTOR_L (12) | 动作 |
|---|---|---|
| 高 | 低 | 正转（冲水杆向下） |
| 低 | 高 | 反转（冲水杆向上） |
| 低 | 低 | 停止 |
| 高 | 高 | **禁止** |

PWM 默认占空比见 `firmware/motor.py` 中 `PRESS_PWM_DUTY_PCT`；用 PC 端 `bench_gui` 测好后写死。

## 冲水动作

1. 设定 PWM 占空比（目标约 6V 等效，以实测为准）
2. 向下运动 **1 s**（H=1，L=0）
3. H、L 拉低，停 **1 s**
4. 向上运动 **1 s**（H=0，L=1）
5. H、L 拉低，停止

一次占用结束若冲水次数 > 1：按上面流程重复，两次之间间隔使用「冲水间隔」。

## 检测与冲水逻辑

空闲 → 占用中（GPIO1 低）→ 离开倒计时（GPIO1 由低变高）→ 冲水 → 空闲

- GPIO1 **低**：宠物在；若正处于离开倒计时，**取消冲水并重新占用**。
- GPIO1 由低变高：宠物离开，开始倒数；倒计时结束才冲水。
- 倒计时期间再次检测到低电平：倒计时清零，回到占用。
- 上电时若 GPIO1 已是高电平，不冲水，保持空闲。
- 冲水过程中电机动作做完再响应下一次检测。

## 硬件调试（PWM / 粉碎）

1. 上传整个 `firmware/` 到板子（至少含 `main.py`、`bench.py`、`pins.py`、`motor.py`、`config.py`）。
2. 把 `firmware/config.bench.json` 复制为板上的 `config.json`（或手动写入 `"bench_mode": true`），然后**按复位键**；上电后会进串口调试，不再开 WiFi。
3. 测完后改回 `config.json` 去掉 `bench_mode` 或设为 `false`，再复位即恢复自动冲水固件。
4. 在项目根目录创建 venv 并启动界面：

```powershell
cd c:\Users\Siven\Desktop\dog_toilet
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r bench_gui\requirements.txt
python bench_gui\app.py
```

3. 连接 USB 串口（115200），调节 PWM、方向与粉碎开关；万用表测实际电压后修改 `PRESS_PWM_DUTY_PCT`。

## 网页

手机连接 ESP32 热点后打开 **http://192.168.4.1** 配置参数（正式固件 `main.py`）。

- 上电后 WiFi 默认开启 **30 分钟**，超时自动关闭。
- 热点名称：`toilet_` + MAC 后 6 位。
- 参数掉电保存；界面中英文可切换。

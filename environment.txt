# dog_toilet PC 开发环境快照（environment 1）
# 生成日期：2026-09-30
# 用途：刷 ESP32-S3 固件（esptool/mpremote）、运行 bench_gui 上位机

================================================================================
一、环境复现步骤（Windows + PowerShell）
================================================================================

1. 安装 Python 3.10+（本机导出时为 Python 3.14.5；3.10–3.12 均可，需已加入 PATH）

2. 进入项目根目录并创建虚拟环境：

   cd c:\Users\Siven\Desktop\dog_toilet
   python -m venv venv

3. 激活虚拟环境：

   .\venv\Scripts\Activate.ps1

   若提示无法执行脚本，可先（当前用户、一次性）：
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

4. 安装依赖（与下方 pip freeze 一致）：

   pip install --upgrade pip
   pip install -r requirements.txt

   或最小安装（仅上位机 + 烧录工具）：
   pip install pyserial esptool mpremote

5. 验证：

   python bench_gui\app.py
   mpremote --help
   esptool version

6. 说明：
   - venv/ 目录不要提交 Git（已在 .gitignore）
   - MicroPython 系统固件 .bin 见 README，需自行放在 firmware/ 或从 micropython.org 下载
   - 板端 Python 文件上传见 README「上传 Python 到板子」
